# Security policy

Grimreach is an experimental game. The current 0.1.x line receives security
reports, but there is no promised response time or long-term support period.

Please use [GitHub's private vulnerability reporting](https://github.com/mozrin/grimreach/security/advisories/new)
for a suspected vulnerability. Do not post exploit details, tunnel tokens, or
other credentials in a public issue. Include the affected version, impact, and
reproduction steps. The owner will coordinate disclosure and any fix through
the advisory.
